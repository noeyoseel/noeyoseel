
# 안녕하세요, 이소연입니다.

**문제를 구조화하고, 직접 구현하고 검증하는 Product Builder입니다.**

공공 SI 프로젝트에서 사업관리(PMO)·품질관리 업무를 수행하며 요구사항과 실제 구현 결과의 정합성을 확인했습니다.

이후 Java·Spring 기반 개발 교육과 팀 프로젝트를 통해 직접 구현하는 경험을 쌓았고, 개인 프로젝트에서는 AI·데이터 기술을 활용해 문제를 해결하는 방법을 실험했습니다.

기술을 적용하는 것 자체보다 **해결하려는 문제에 적합한 방법인지 판단하고, 실제 결과로 확인하는 과정**을 중요하게 생각합니다.
